BLOQZ surveille votre webcam et verrouille automatiquement votre session dès que vous vous éloignez. Rien n'est enregistré ni envoyé.

Verrouillage à l'absence

Détection de visage en temps réel. Un compte à rebours s'affiche avant le verrouillage.

100 % local

Les images sont analysées sur votre appareil. Aucune capture stockée, aucune transmission.

Fonds personnalisables

Choisissez ou importez votre image ; les transitions se font par morphing.

Windows & Linux

Verrouillage natif via l'API Windows ou loginctl / xdg-screensaver sous Linux.

Installation — Windows

  1. Téléchargez BLOQZ.exe avec le bouton ci-dessus.
  2. Double-cliquez sur le fichier.
  3. Si Windows affiche « SmartScreen », cliquez Informations complémentaires → Exécuter quand même (l'app n'est pas encore signée numériquement).
  4. Au premier lancement, acceptez la politique de protection des données, puis placez-vous devant la caméra.

Installation — Linux

  1. Installez Python 3, puis récupérez le code source.
  2. pip install -r requirements.txt
  3. python3 isdhine.py (ou ./run_bloqz.sh)
Protection des données. BLOQZ traite le flux de votre webcam uniquement pour détecter votre présence, de façon locale et en temps réel. Aucune image n'est conservée ni transmise. Le traitement repose sur votre consentement, conformément à la Loi n°2017-20 (Code du numérique du Bénin) et à la Loi n°2020-35. Un écran de consentement s'affiche avant toute utilisation.
